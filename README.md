Expense Manager to aplikacja internetowa stworzona w architekturze ASP.NET Core MVC i Entity Framework Core, służąca do kompleksowego zarządzania oraz kontrolowania budżetu domowego.

# Funkcjonalności

## Lista wydatków
Na głównej stronie aplikacji możemy przeglądać listę naszych wydatków. Możemy również dodawać nowe wydatki lub edytować i usuwać poprzednie.
<img width="1870" height="916" alt="image" src="https://github.com/user-attachments/assets/e96e48f3-b84c-40ba-8cee-d1def74ca6e0" />

## Dodawanie/Edycja wydatku
Przy dodawaniu lub edycji wydatku mamy prosty formularz z walidacją danych. Mamy do wypełnienia pole opis, kwotę oraz wybranie kategorii i daty wydatku.
<img width="1870" height="918" alt="image" src="https://github.com/user-attachments/assets/b309bac1-c639-4297-827a-a9f76af52a0e" />

## Analityka Wydatków
W podstronie analityki mamy dostępne wykresy dzielące wydatki na kategorie w wykresie kołowym, oraz sumę wydatków z poszczególnych miesięcy
